# 要件定義書 (EEVN - React Native / Expo 版)

## 1. プロジェクト概要・動作環境
* **アプリ名**: EEVN（EEV React Native / Expo Port）
* **ターゲットプラットフォーム**: Android（Android SDK / 実機確認環境、パッケージ名: `com.example.eevn`）
* **仕様フレームワーク・技術スタック**:
  * **UI/ロジック**: React Native (`0.88.1`) + Expo (`~58.0.26` Prebuild / Development Build) + TypeScript (`~6.0.3`)
  * **周辺ライブラリ**: `expo-sqlite`（SQLite 永続化）, `expo-image`（高速画像表示・サムネイル表示）, `expo-keep-awake`（閲覧中画面常時点灯）, `@react-native-async-storage/async-storage`（設定保存）, `react-native-gesture-handler` / `react-native-reanimated`（ジェスチャ・アニメーション）, `@expo/vector-icons`（UIアイコン）, `expo-modules-core`（ローカルモジュール連携）
  * **極薄 Kotlin ローカルモジュール（`modules/eev-storage`）**: `MANAGE_EXTERNAL_STORAGE` 権限要求、高速ストレージ走査、最大辺256pxの永続サムネイル生成（`filesDir/folder_thumbs`・`filesDir/bookshelf_thumbs`）、および安全なファイル/フォルダ削除を担当する。
* **アーキテクチャパターン**: MVVM（カスタムフックによる ViewModel 層分離）＋ Core / Feature 単方向依存
* **開発・ファイルサイズルール**: 1ファイル上限は約400行とし、すべてのコードに日本語Docコメント（責任・影響する状態・潜在的エラー）を付与する。

## 3. 詳細機能要件（フェーズ1）

### 3.1 ファイルエクスプローラ機能（`features/explorer`）
* **全ファイルアクセス権対応**: Android 11+ の `MANAGE_EXTERNAL_STORAGE` 状態を確認し、未許可時はヘッダーバナー等から許可画面へ誘導する。
* **階層ブラウズ・パンくずリスト・検索**: フォルダ遷移履歴（戻る対応）、パンくずリストによる任意階層ジャンプ、フォルダ内リアルタイム部分一致検索を提供する。
* **表示モード・表示オプション・個別ソート**:
  * リスト表示 / グリッド表示（2〜4列）をワンタップで切り替え。
  * サムネイルサイズ（小・中・大）と付加情報（日付・画像枚数）表示設定（本棚画面と共有）。
  * フォルダ並び順（名前昇降・日時昇降・画像数昇降・カスタム昇順/降順）とファイル並び順を個別に設定可能。
* **通常フォルダの永続サムネイル保存と2段階即時表示（新機能②）**:
  * サムネイル画像は OS の自動削除を受けないアプリ内部永続領域 `filesDir/folder_thumbs` に保存し、メタ情報（`last_modified`, `image_count`, `thumb_path`, `has_trans_db`, `has_sub_dirs`）を `folder_cache.db` に永続化する。
  * フォルダ開時にまず `folder_cache.db` のキャッシュ内容を即座に画面へ反映し、バックグラウンドで `lastModified` 差分を照合して変更・未キャッシュ分のみ再生成する。
* **本棚未登録フォルダの一括削除（サブフォルダを含まない）（新機能①）**:
  * ヘッダーボタンから「現在開いているフォルダの直下フォルダ」のうち本棚（お気に入り）に未登録のものを抽出して一括削除する。
  * **安全保護ルール**:
    * 直下の通常ファイル（画像等）は一切削除しない。
    * 本棚登録済みフォルダ、直下にサブフォルダを含むフォルダ、配下に本棚登録済みの子孫フォルダを含むフォルダはすべて削除対象から除外（保護）する。
  * 実行前に削除対象フォルダの**件数とフォルダ名一覧**を確認ダイアログ（`DeleteNonFavoriteFoldersDialog`）で提示し、ユーザー承認後のみ削除＋関連キャッシュ削除＋再読み込みを実行する。
* **単体操作（長押しメニュー）**: フォルダのお気に入り登録/解除、および個別削除（確認ダイアログ付き）。

### 3.2 本棚機能（`features/bookshelf`）
* **専用データベース & 永続サムネイル**: `bookshelf.db`（フォルダメタデータ・カスタム順序・カテゴリ・フォルダ紐付け）と `filesDir/bookshelf_thumbs` を使用し、ディスク走査なしの2段階高速表示を行う。
* **カテゴリ管理・複数割り当て・複数選択AND絞り込み**:
  * ヘッダーのカテゴリ管理アイコンからカテゴリの新規追加・名前変更・削除が可能。
  * フォルダ長押しで「カテゴリ複数選択チェックボックス＋新規カテゴリ即時作成＋お気に入り解除」の統合ダイアログを表示する。カード/リスト行にも所属カテゴリを表示する。
  * ヘッダー直下の横スクロール可能なフィルタチップバー（「すべて」「未分類」＋登録済みカテゴリ）により、通常カテゴリの複数選択（**すべてに所属するAND検索**）および「すべて」「未分類」との排他切り替えで絞り込む。
* **カスタム並び順＆並べ替え**: カテゴリ絞り込みなし（「すべて」）・検索空の状態でリスト/グリッドアイテムの並び替えを行い、`bookshelf.db` の `custom_order` に永続保存する。
* **共有設定・ビューワ直結起動**: 検索、表示切替、ソート設定、表示オプション、設定画面遷移を提供し、フォルダタップで直接画像ビューワを起動する。

### 3.3 画像ビューワ機能（`features/viewer`）
* **フルスクリーン・ページ送り**: 画面常時点灯（`expo-keep-awake`）、右端/左端タップによる前/次移動、トリプルタップでメニュー（終了／次のフォルダへ移動／最初の画像に戻る）表示。
* **漫画モード**: 見開き画像を右半分（`RIGHT_HALF`）→左半分（`LEFT_HALF`）の順で切り出し表示する。
* **ビューワ独自ソート＆ボトムシート**: 名前昇降・日時昇降・**カスタム順（昇順）・カスタム順（降順）** を選択可能。
* **フォルダまたぎ移動**: 通常起動時は親ディレクトリ直下のサブフォルダを非ループ移動、本棚起動時は**本棚で絞り込み中のフォルダ群**を対象にビューワのソート順（カスタム昇順/降順含む）に従って**循環（ループ）移動**する。

### 3.4 設定画面・戻るボタン制御（`features/settings`, `core/ui`）
* 漫画モード、隠しファイル表示、通常フォルダ永続サムネイル＆メタデータキャッシュの一括クリアを提供。
* Android システムの戻るボタンを画面・検索・シート状態に応じて適切にルーティングする。

## 4. フォルダ構成ルール（機能単位 / Feature-Based）

```text
EEVN/
├── modules/
│   └── eev-storage/              # 極薄 Kotlin ネイティブモジュール（権限・高速走査・永続サムネ生成・削除）
├── src/
│   ├── core/                     # 全体共通基盤（Feature に依存しない単方向依存）
│   │   ├── models/               # 共通型・Enum (types.ts)
│   │   ├── storage/              # 設定ストア (AppSettingsStore.ts), 通常フォルダDB (FolderMetadataDb.ts), ソート (SortUtils.ts)
│   │   └── ui/                   # 共通テーマ・戻る制御 (AppTheme.ts, AppBackHandler.ts)
│   └── features/                 # 機能単位モジュール群 (Feature-Based)
│       ├── explorer/             # エクスプローラ画面・ViewModel・ダイアログ群
│       ├── bookshelf/            # 本棚画面・ViewModel・DB・カテゴリダイアログ・行/カードUI
│       ├── viewer/               # 画像ビューワ画面・ViewModel・フォルダナビゲータ・ダイアログ群
│       └── settings/             # 設定画面・ViewModel
└── App.tsx                       # エントリポイント・画面ルーティング統合
```
